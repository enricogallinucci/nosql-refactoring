## Outline

The `queries` folder contains all queries in YML files; for each workload, a list of queries is reported indicating the weight (i.e., the frequency), the SQL code, and the list of parameters that must be dynamically generated to execute the query.

The `migrations` folder contains SQL files to execute migrations from one database version to another.

The `scripts` folder is the main reference for the creation of the databases and execution of experiments.
- IMPORTANT: in the `scripts` folder, a `config.py` file must be created by copy-pasting the `config-example.py` file and filling it with your credentials to access.
- Files in the `data_creation_utils` folder contain all references to download the data from [CasJobs](https://skyserver.sdss.org/CasJobs/default.aspx) and put it in a PostgreSQL database. You can either:
  - Replicate the data by following the steps in those files.
  - Download the dump of the PostgreSQL database at [this link](https://big.csr.unibo.it/downloads/nosql-refactoring/sdss_relational2.zip) (205MB) and then create the NoSQL versions by executing the scripts in the `create_nosql_versions` folder.
- Script `4_simulations.ipynb` contains the code to run the queries in the `queries` folder; results are materialized in the `results` folder and are **not** tracked in the repository.
- Script `5_analysis.ipynb` contains the code to extract statistics from the output files in the previous step.
- Script `6_migrations.ipynb` contains the code to run the migrations in the `migrations` folder; results are materialized in the `results` folder and are **not** tracked in the repository.
- Script `8_storage.ipynb` contains the code to calculate statistics about the storage occupation of databases.
- Scripts `9_migration_optimization_[others/ours].py` contain the code to optimize migrations by finding the best order to execute migration queries; the "ours" file contains the code of our heuristic, while the "others" file contains code of the other tested heuristics, together with the exhaustive search.

The `results` folder contains the reuslts of the experiment. Besided the untracked files generated by local executions of scripts, this repository contains:
- A `Results.xlsx` file, used for internal reference.
- A `Statistics.xlsx` file, containing the full summaries of experimental execution of the datasets at each scale.
